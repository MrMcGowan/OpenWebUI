# Windows Installation Guide

## Overview
This guide provides step-by-step instructions for installing Open WebUI on Windows Server 2022 using the 
setup.exe installer.

## Prerequisites
- Windows Server 2022 (Build 20348 or later)
- Administrator privileges
- 4 GB RAM minimum (8 GB recommended)
- 10 GB free disk space minimum
- Internet connection for initial setup

## Installation Steps

### 1. Download the Installer

Download the latest `OpenWebUI-Setup-{version}-Win64.exe` from the releases page or build it from source.

### 2. Run the Installer

1. Right-click the installer and select **Run as administrator**
2. Follow the installation wizard:
   - Accept the license agreement
   - Choose installation directory (default: `C:\Program Files\Open WebUI`)
   - Select additional tasks:
     - Create desktop icon (optional)
     - Create start menu icon
     - Start service after installation
     - Configure auto-start with Windows

### 3. Firewall Configuration

The installer automatically configures Windows Firewall to allow Open WebUI on port 8080.

To manually configure:

```powershell
netsh advfirewall firewall add rule name="Open WebUI" dir=in action=allow protocol=TCP localport=8080
```

### 4. Access the Application

After installation completes, access Open WebUI:

- Local access: `http://localhost:8080`
- Network access: `http://<server-ip>:8080`

### 5. Initial Setup

1. Create the first admin account when prompted
2. Configure your AI model connections (Ollama, OpenAI, etc.)
3. Customize settings as needed

## Service Management

### Using Services Console

1. Press `Win + R`, type `services.msc`, press Enter
2. Find "Open WebUI Service"
3. Right-click to Start, Stop, or Restart

### Using PowerShell

```powershell
# Start the service
Start-Service OpenWebUIService

# Stop the service
Stop-Service OpenWebUIService

# Restart the service
Restart-Service OpenWebUIService

# Check service status
Get-Service OpenWebUIService
```

### Using Command Prompt

```batch
# Start the service
net start OpenWebUIService

# Stop the service
net stop OpenWebUIService

# Check service status
sc query OpenWebUIService
```

## Configuration

### Configuration File Location

The main configuration file is located at:
```
C:\Program Files\Open WebUI\data\.env
```

### Common Configuration Options

Edit the `.env` file to customize:

```ini
# Server Configuration
WEBUI_HOST=0.0.0.0
WEBUI_PORT=8080

# Data Directory
DATA_DIR=.\data

# Security
WEBUI_SECRET_KEY=<auto-generated>

# Optional: External AI Service URLs
OLLAMA_BASE_URL=http://localhost:11434
OPENAI_API_BASE_URL=https://api.openai.com/v1
```

After editing, restart the service:
```powershell
Restart-Service OpenWebUIService
```

## Troubleshooting

### Service Won't Start

1. Check Windows Event Viewer:
   - Press `Win + R`, type `eventvwr.msc`
   - Navigate to Windows Logs > Application
   - Look for errors from "OpenWebUIService"

2. Check service logs:
   ```
   C:\Program Files\Open WebUI\logs\openwebui_stdout.log
   C:\Program Files\Open WebUI\logs\openwebui_stderr.log
   ```

3. Verify port 8080 is not in use:
   ```powershell
   netstat -ano | findstr :8080
   ```

### Cannot Access from Network

1. Verify Windows Firewall rule:
   ```powershell
   Get-NetFirewallRule -DisplayName "Open WebUI"
   ```

2. Add firewall rule if missing:
   ```powershell
   New-NetFirewallRule -DisplayName "Open WebUI" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
   ```

3. Check if `WEBUI_HOST` is set to `0.0.0.0` in `.env` file

### Database Issues

If the database becomes corrupted:

1. Stop the service
2. Backup the database:
   ```powershell
   Copy-Item "C:\Program Files\Open WebUI\data\webui.db" "C:\Program Files\Open WebUI\data\webui.db.backup"
   ```
3. Delete the database file (a new one will be created)
4. Start the service

## Uninstallation

### Using Control Panel

1. Open **Apps & Features** or **Programs and Features**
2. Find "Open WebUI"
3. Click **Uninstall**
4. Follow the uninstaller wizard

### Using PowerShell

```powershell
# Find the uninstaller
$uninstaller = Get-ChildItem "C:\Program Files\Open WebUI" -Filter "unins*.exe" | Select-Object -First 1

# Run uninstaller silently
Start-Process $uninstaller.FullName -ArgumentList "/SILENT" -Wait
```

The uninstaller automatically:
- Stops the Windows service
- Removes the service registration
- Removes firewall rules
- Deletes application files

**Note:** User data in the `data` folder may be preserved. Delete manually if needed.
